# Login and Sign Up UI

A front-end login and registration screen built with HTML, CSS, and JavaScript. It demonstrates a 3D flip-panel transition between the login and sign-up views.

## Run locally

Open `index.html` in a browser, or serve this folder with a local static file server.

## Project files

- `index.html` — login and sign-up screen markup
- `style.css` — layout and flip-animation styles
- `script.js` — panel switching interactions

## Scope

This is a visual front-end demo. It does not authenticate users, save accounts, or send form data to a server. The social links are placeholders.
